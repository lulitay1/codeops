1. The difference between git and github 
    Git is a version control while github is a platform that hosts our github repos.
2. The purpose of Terminal
    Terminals are used to instruct our computer to do something using text based commands.
3. What git add does
    git add stages or prepares our changed files to be commited.
4. Purpose of git commit
    git commit helps us save the snapshot of the current version of our code.
5. Daily git workflow
    1. initalize git (git init)
    2. change or edit files
    3. Stage changes for commit (git add)
    4. commit changes (git commit -m "commit message")
    5. push our change (git push)
