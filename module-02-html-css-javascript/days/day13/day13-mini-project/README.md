This is a business card for YOYO cafe located around Bole, Addis Ababa.
Lists of CSS rules implemented
1. root palette and spacing scale defined as variables and used as var() through out the css code.
2. border-box set to box-sizing globally using *
3. Body font set to a readable font.
4. card centered using padding, marging, border and border radius.
5. typography hierarchy 
    Bussiness name as h1
    Services as h2
    and body text as p
6. contact button that changes its lightness using pseudoclass :hover
7. A pseudo-element ::after implemented for list with contect "---".
