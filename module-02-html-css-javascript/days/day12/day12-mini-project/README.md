# Habesha Eatery

A simple two-page HTML5 website for a fictional Ethiopian restaurant.

## Features
- Reservation form
- Contact form
- Menu table with ETB prices
- Opening hours table
- Restaurant image and Fictional Google Map
- Semantic HTML5 and accessible navigation

## Technologies
- HTML5

## Run
Open `index.html` in your web browser and use the navigation links to explore the site.
