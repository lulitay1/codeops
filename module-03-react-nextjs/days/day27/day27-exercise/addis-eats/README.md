# Addis Eats

A simple React menu application built with Vite.

## What it is

Addis Eats is a static Ethiopian food menu created to practice React fundamentals.

The project demonstrates:

- JSX
- React components
- Props
- Destructuring
- Component composition
- Arrays
- map()
- React keys

## Components

### Header

Displays the Addis Eats title and introduction.

### Dish

A reusable component that receives:

- name
- price

as props and displays the dish information.
